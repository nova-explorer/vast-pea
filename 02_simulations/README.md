# Simulations

Simulations were ran in array for the different replicates on the [MeluXina](https://www.luxprovide.lu/meluxina/) and the [Iris](https://www.uni.lu/research-en/core-facilities/hpc/infrastructure/) HPCs.
For schematics highlighting these steps, please refer to the supporting information Figures S1 and S2 in ***ADD LINK TO PAPER***

Do note that all DGEBA/AFD and DGEBA/DDS simulations used a timestep of 1fs, while the simulations for DGEBA/AFD-OAPS and DGEBA/AFD-OPS used timestep of 0.5fs (and 0.25fs at the beginning of BER).

The current files are pulled from the simulations for the DGEBA/AFD-OPS system since the nanocomposite systems were slightly more complicated and prone to crashes.
Thus, the simulations required extra steps for those systems.
Steps could be skipped for simpler systems are directly mentioned.

BERs are not enabled for the DGEBA/DDS system. The simulations files need to be adjusted by removing the `fix bond/react` associated commands.

The pre/post-reaction templates and map files are generated by LUNAR but verified and corrected by hand.

The `SEED` variable was generated by adding the `-var SEED $RANDOM` argument to the lammps submission script

The Preparation and BER simulations are inspired by [Singh *et al.*](https://doi-org.proxy.bnl.lu/10.1016/j.cplett.2020.137966).

The Young's modulus simulations are adapted from the [RFR-method](https://github.com/CMMRLab/RFR_stress_strain/tree/main).

## Files
- `ber_pre.lmpmol`, `ber_post.lmpmol` and `ber.map`: pre/post-reaction templates for disulfide BERs along with the associated map file
- `poly*_pre.lmpmol`, `poly*_post.lmpmol` and `ber.map`: pre/post-reaction templates for both curing reactions along with their associated map file
- `run.*.in`: LAMMPS script files to execute
- `run.init.in`: Contains initialization parameters common to all simulations, namely related to interactions styles. The Definitions section may change between simulations.
- `system_cell.data`: Example of an initial data file for DGEBA/AFD-OPS.

## Execution
- [Create initial system_cell.data files](docs/CONTRIBUTING.md)
- Run preparation simulations (in order):
    - `run.equil1.in`: 2ns NVT simulation to let the monomers in the sparse system agglomerate
    - `recenter.py`: custom python script to center the monomer agglomeration and remove excess volume (can be skipped for simple systems)
    - `run.equil2.in`: 1ns NVT to relax the new box (can be skipped for simple systems). 2ns NPT to let the density converge
    - `run.annealing1.in`: 20 steps of 0.5ns NPT alternating between 1K and 600K to help density converge. Followed by a 5ns NPT run for equilibration
    - `run.replicate.in`: Replicates the system 8x, then runs 10ns NPT
    - `add_data_labels.py`: custom python script to restore type labels that get removed by the `replicate` command
    - `run.curing.in`: 10ns NVT with curing reactions enabled. Will save a few data files at different conversion levels
    - `charge_rescale.py`: adjusts the charge of certain atoms to balance the system's net charge to 0
    - `run.annealing2.in`: Another annealing step. May require multiple submissions for HPCs with short max walltime. Several restart files are created for that purpose

- Run production run simulations (no specific order):

    - BER (array was shifted to do all temperatures in parallel and manage replicates in different submissions)
        - `run.pre.in`: 2ns NPT at specific temperature at 0.5fs timestep
        - `run.025.in`: 5ns NPT at specific temperature with BERs enabled at 0.25fs timestep
        - `run.05.in`: 15ns NPT at specific temperature with BERs enabled at 0.5fs timestep
        - For simple systems, the 3 steps can be run at 1fs timestep, thus skipping the second step
        - May require multiple submissions for HPCs with short max walltime. Several restart files are created for that purpose
        - This is repeated for the following temperatures: 325K, 350K, 375K, 400K, 425K, 450K, 500K, 600K

    - Dilatometry:
        - `run.tg.in`: Start with a 4ns NPT equilibration at 600K. Temperature is then decreased by 20K every 2ns until 200K is reached.
        - BERs are enabled throughout all steps
        - May require multiple submissions for HPCs with short max walltime. Several restart files are created for that purpose

    - Young's modulus :
        - `run.young.in`: Deforms the system at a specified strain rate up to a specified strain
        - BERs are enabled throughout all steps.
        - Since these are fairly short, x, y and z runs were realized sequentially in the same submission

## Requirements
- LAMMPS 2022+: Use the most recent version available as the REACTION package receives frequent useful updates
    - Packages: MOLECULE, KSPACE, CLASS2, OPENMP and REACTION
    - Versions used:
        - MeluXina: 2Aug2023_update2-foss-2023a-kokko
        - Iris: 29Aug2024_update2-foss-2024a-kokkos
- Python 3.6+: Version used for development was 3.12.3, but the HPCs ran 3.6.8
    - `recenter.py` typically was executed locally and not on the HPCs due to it's more involved dependencies:
        - xarray
        - pandas
        - numpy
        - scipy
        - glob
